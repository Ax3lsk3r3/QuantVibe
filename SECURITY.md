# Política de seguridad

## Versiones soportadas

| Versión | Soporte |
|---------|---------|
| 0.2.x   | ✅      |
| < 0.2   | ❌      |

## Reportar una vulnerabilidad

Usa el reporte privado de GitHub:
**Security → Advisories → New draft security advisory**, o abre un issue marcado como
`security` sin detalles técnicos sensibles y continuaremos en privado.

No uses issues públicos para vulnerabilidades explotables.

## Nota sobre trading

Este proyecto conecta con brokers. Si encuentras una forma de que se envíen órdenes reales
sin las dos guardias explícitas (`--submit` + `VIBE_ALLOW_ORDERS=1`), eso es una
vulnerabilidad crítica: repórtala de inmediato por la vía privada.
